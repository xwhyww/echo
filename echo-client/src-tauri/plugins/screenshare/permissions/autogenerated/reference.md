## Default Permission

Drive the native iOS screen-share sidecar: probe support, start and stop a
broadcast, and mute its captured app audio. All four are triggered by the user
pressing the share control, and starting a broadcast additionally requires the
system's own confirmation sheet.

#### This default permission set includes the following:

- `allow-is-supported`
- `allow-start`
- `allow-stop`
- `allow-set-audio-muted`
